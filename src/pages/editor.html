Editor

The design goal was that cost scales with the viewport, not the file. Three decisions do most of that, and everything else on this page is ordinary editing done in the ordinary way.

What it is built on

A persistent rope

Whose interior nodes sum bytes, UTF-16 units and newlines — so a line number, a byte offset and the position AppKit is asking about are all the same walk, and an edit shares the parts of the tree it did not touch.

Highlighting scoped to the bytes on screen

tree-sitter parses the file, and the query that turns a parse tree into colours is run over the viewport rather than the document. A 100,000-line file costs what eighty lines cost.

A parser that may land a frame late

It runs off the main thread and is allowed to arrive after the keystroke that caused it. The rope is authoritative for text and the parser only for colour, so the worst a late parse can do is colour a character the wrong way for one frame.

Editing

⌘/ comments what is selected

At the indent the lines share, blank lines neither commented nor counted, and the selection still covering the same text afterwards. It answers to ⌘/ on every keyboard layout.

It uses the file's language and not the fence's: ⌘/ inside a Swift block in a markdown file refuses and says markdown has no line comment, rather than putting // in the prose.

Completions arrive with their holes

A server that answers with union() $0 means the caret goes where $0 is — not that a dollar sign should be typed into the file. Every stop leaves its default text, the first is selected so typing replaces it, ⇥ moves to the next and ⇧⇥ back.

⇧F6 renames

Through the language server, worked out in full before anything is written, across every file it touches — and undone by one ⌘Z. Open documents are changed through the rope rather than on disk, so a tab does not reload underneath you.

The motions somebody's hands already know

⌃B and ⌃F a character, ⌃A and ⌃E to the ends of the line, ⌃K to the end of it, ⌃O to open a line below. A character is a grapheme cluster, so the caret does not come to rest inside an accent written as two code points.

Find belongs to the tab it searched

⌘F searches this file; the match ⌘G is on is the loudest thing on the page, and the others are quieter than it on purpose. A search that found nothing says so in red, and so does a regular expression that did not run. Replace is in the same band, with the highlights following the text as it is edited.

⇥ follows the file, not a setting

The file's habit is read once at its head — which of tabs or spaces begins more of its indented lines, and for spaces the most common run — and said in the footer as Tabs or Spaces: 2. ⇥, ⇧⇥, a block indent and return's auto-indent all insert one level of it, so a two-space values.yaml stops gaining a tab on the line somebody is typing.

The chip opens a menu, and choosing converts the file level by level — one leading tab, or the old width in spaces, becoming one level of the new — as a single edit, so one ⌘Z takes the whole conversion back and the chip goes back with it.

Folding, for every language

Where a grammar ships a folds.scm — or one is written here, as Java's is — the fold points are the ones that query names. Where it does not, they are derived from the parse tree: any node spanning more than one line.

What the gutter says

Which of these lines have I changed since HEAD? is the question asked most often about an open file, and it had no answer here short of the commit page or a terminal.

  • A bar beside added and modified lines, and a wedge where deleted lines vanished from. Staged and unstaged alike, so the marks answer since HEAD rather than since the index.
  • Anchored the way breakpoints are, so they stay put while somebody types. One git diff per file per save, reload or repository change — never per keystroke.
  • Nothing on an untracked file: one that is entirely new would be entirely coloured, which says nothing at all.
  • Show Blame is in the gutter's own menu, on the toggle ⌥⌘B already shares. Right-clicking the line numbers used to open the text area's menu, which is how blame came to be reported as missing after months of shipping.
  • A breakpoint outlives the session it was set for, which is most of what makes it a breakpoint rather than a command.

What a tab can be

A tab is source, or a rendered view of it, or both split either way — and the choice is remembered per file, so a tab comes back in the mode it was left in. ⌥⌘Z wraps, ⇧⌘V previews markdown, ⌘\\ splits. A file dropped on the editor opens in it.

Files with no readable source open as what they are: a picture at the size it was taken, zooming to the pixels; an SVG drawn rather than shown as markup; a PDF as a PDF. A binary or oversized file opens as a tab explaining itself, over a hex viewer that memory-maps the file and draws only the rows on screen — and it is called binary whatever its size, rather than told it is too large to open as text. Diagrams and 3D models have pages of their own.

A video plays in a tab. An .mp4, .mov or .m4v opens shaped like a picture's tab, with the system's transport controls. It never speaks uninvited: paused on its first frame, paused again when you switch away, and it does not resume when you come back. A .webm keeps the old notice, because a player spinning over a black rectangle is worse than a notice that is honest.

Space opens Quick Look for what the system genuinely previews — an image, a video, a PDF — as it does everywhere else on this machine. Everything else keeps the provisional open, which is what Space is for in a tree of source files.

And a picture on the clipboard pastes as a file. In the tree it lands where a pasted file would, with the row open for renaming. Over a Markdown or HTML document it goes into images/ beside the document and puts a reference at the caret, the caret inside the empty description so the next thing typed is the alt text. Text on the board still pastes as text, and a language with no picture syntax pastes nothing.

Twenty-four languages are highlighted and folded, and which of them also have a server, a debugger and a build tool is the languages page. The colours all of this is drawn in are the themes page, and are files you can write. A .env or a SOPS file opens with its values already unreadable — the secrets page.
